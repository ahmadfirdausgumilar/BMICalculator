# Kalkulator BMI (JavaFX)

Tugas Pemrograman Berorientasi Objek - Pertemuan 10 (GUI dengan JavaFX).

Aplikasi sederhana untuk menghitung Body Mass Index dari berat (kg) dan tinggi (cm),
lengkap dengan kategori hasilnya.

## Cara menjalankan
1. Pastikan JDK 17+ terpasang
2. Buka project di NetBeans (Maven)
3. Jalankan `mvn clean javafx:run` atau klik Run Project

## Teknologi
- Java, JavaFX 21, FXML, Maven
